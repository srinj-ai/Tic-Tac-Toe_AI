# 🎮 Tic Tac Toe AI Bot

A modern and upgraded Tic Tac Toe game built using **Python + Tkinter**, featuring a smart AI with multiple difficulty levels and a multiplayer LAN mode. The project offers a clean UI, smooth gameplay, and a complete scoreboard + rematch system.

---

## 🚀 Features

### 🧠 **Single Player (AI Mode)**

* Multiple AI difficulty levels:

  * Easy
  * Medium
  * Hard
  * Impossible
* Smart AI decision-making
* Smooth animations and modern GUI

### 🌐 **Multiplayer Mode (LAN)**

* Play with friends using local network
* Automatic connection system
* Real-time gameplay sync

### 🎨 **Modern GUI**

* Clean interface built with Tkinter
* Responsive layout
* Player indicators & highlights

### 🏆 **Scoreboard System**

* Tracks scores for Player X, Player O, and Ties
* Score persists across rematches

### 🔁 **Rematch System**

* Restart a match instantly
* No pop-ups on win/tie — results are shown smoothly on-screen
